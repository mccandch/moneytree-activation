Privacy Policy

The Money Tree desktop application · last updated 4 September 2026

The Money Tree is a Windows desktop application used by its author and a small number of named individuals. It runs entirely on the operator's own computer. There is no Money Tree server, no account system, no analytics, and no telemetry of any kind.

What is collected

One thing: the email address of the Google account used to activate the application, together with an identifier derived from the computer it was activated on and the time of activation.

This happens once, the first time the application runs on a given machine. The application requests only the openid, email and profile scopes — the minimum needed to learn a verified email address. It requests no access to Gmail, Drive, Calendar, Contacts, or any other Google service.

What it is used for

Only to check whether the address is permitted to run the application. The list of permitted accounts is published as salted hashes, so the list itself does not disclose anyone's address. If the address matches, the machine is activated; if it does not, the application does not run.

Where it is stored

In a single file in the application's own data folder on the operator's computer. It is not transmitted anywhere. It is not uploaded, backed up, or synchronised by the application. It stays on that machine and is readable by whoever uses that machine.

What is never done with it

  • It is never sold, rented, or shared with any third party.
  • It is never used for advertising, profiling, or marketing of any kind.
  • It is never sent to any server operated by the developer, because there is none.

After activation

Once a machine is activated, the application never contacts Google again. It stores no Google refresh token and holds no ongoing access to the Google account. Signing in a second time is not required and does not happen.

Deleting the data

Deleting the application's data folder, or the activation file inside it, removes the stored address from the machine completely. To revoke the application's one-time access from the Google side, use Google Account → Third-party apps.

Children

The application is not directed at children and is not made available to the general public.

Changes

If this policy changes, the revised version replaces this page and the date above is updated.
