The Money Tree

A private desktop application for automated options trading through Interactive Brokers.

The Money Tree is a Windows desktop application built and maintained by Chad McCandless for his own use and for a small number of named individuals. It connects to Interactive Brokers Trader Workstation on the machine it runs on, evaluates market-regime signals, and places and manages options orders according to templates the operator configures.

It is not sold, not distributed publicly, and not available for general sign-up. This page exists because the application uses Google Sign-In once, at activation, and Google requires a home page and a privacy policy for any application that does so.

How Google Sign-In is used

  • The first time the application runs on a machine, it asks the operator to sign in with Google.
  • It reads the verified email address from that sign-in and checks it against a list of permitted accounts, published as salted hashes and verified by signature.
  • If the address is on the list, the application records the activation locally on that machine and never contacts Google again — not on any later launch, and not in the background.

Google Sign-In is used solely to confirm identity at activation. The application requests no access to Gmail, Drive, Calendar, Contacts, or any other Google service, and holds no credentials that would let it reach one.

Privacy

The privacy policy sets out exactly what is collected, where it is stored, and what it is never used for.
